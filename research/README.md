## 证据等级说明

- **立场声明（Position Stand）**：学科权威机构对某问题给出的官方立场，由专家组基于现有证据制定，是指导实践的最高等级文件之一。
- **伞形综述（Umbrella Review）**：对多个系统综述再进行汇总分析，站在证据金字塔顶端。
- **1RM**：一次能举起（或完成动作）的最大重量，衡量力量水平的基准。
